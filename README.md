# Умный кредитный кабинет предпринимателя

Прототип для хакатона: путь малого и микробизнеса от выбора финансирования до результата рассмотрения заявки, связанный с рабочим местом сотрудника банка.

**Текущий этап: demo-0.2 принят, начинаем реализацию backend.** Сначала фиксируем структуру; FastAPI, модели, миграции и авторизацию реализуем отдельной веткой. Frontend и Docker разрабатывают Ксюша и Дима.

Границы MVP и demo-0.2 согласованы. Рабочий вариант frontend — React/TypeScript/Vite; окончательный выбор инструмента остается за Ксюшей. Пока создана структура без запускаемого приложения. Инструкции запуска добавляются вместе с backend.

## Структура проекта

```text
src/credit_cabinet/       Python-пакет сервиса
  api/                   HTTP-роутеры, зависимости, обработка ошибок
  core/                  Конфигурация, безопасность, логирование
  db/                    Engine, сессии SQLAlchemy, базовая модель
  models/                ORM-модели demo-0.2
  schemas/               Входные и выходные Pydantic DTO
  services/              Прикладные действия и транзакции
  integrations/          Будущие адаптеры демо-источников и LLM
migrations/versions/     Версионируемые миграции Alembic
tests/                   Тесты backend
demo_data/demo_0_2/       Набор Валеры и Софии, отдельно от кода
frontend/                Область Ксюши
```

Исходники находятся в `src/`, тесты и миграции — вне устанавливаемого Python-пакета. Точка входа будет `python -m credit_cabinet`. Зависимости фиксируем в корневых `pyproject.toml` и `uv.lock`; конфигурацию запуска — в `.env.example`. Docker/Compose и reverse proxy добавляет Дима в корне, исходники frontend — Ксюша в `frontend/`. Пустые каталоги отмечены `.gitkeep`; при появлении файлов отметки убираем.
