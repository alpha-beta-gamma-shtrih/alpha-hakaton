# Умный кредитный кабинет предпринимателя

Прототип для хакатона: путь малого и микробизнеса от выбора финансирования до результата рассмотрения заявки, связанный с рабочим местом сотрудника банка.

**Текущий этап: персональные условия React + FastAPI demo-0.3.** Работают авторизация, импорт C01/C02, сохраняемые черновики, неизменяемые отправки, локальные ФНС/БКИ, 15 правил решения, автоматическое решение, дозапрос/новая отправка, технический повтор сотрудником и предварительное сравнение вариантов. Работают банковская очередь/карточка, история версий/оценок, ручной дозапрос и решение с разграничением публичного обоснования и внутреннего комментария. Подготовленные CSV привязываются к заявкам и снимкам; скачивание проверяет права и SHA-256. AI объясняет заявку и сравнивает варианты на рассчитанных backend факторах; есть сохраненные отчеты, актуальность и явный fallback.

Проверка: 387 автоматических тестов, включая персональные ставки и обновление заполненной БД, в полном прогоне, включая PostgreSQL 17.11, права и перезапуск. Еще три опциональных сценария прошли с настоящей qwen3:4b; замеры — docs/ai_benchmark.json. Ruff, миграции и сборка wheel прошли. Актуальная миграция — 0005_personal_pricing. Подробности — BACKEND.md и AI_CHECK.md.

Границы MVP и demo-0.2 согласованы. Frontend Ксюши на React/TypeScript/Vite включен в frontend/ и проверен с реальным API. Локально API и Vite запускаются в двух терминалах; Docker пока готовит Дима. Удаление неотправленного черновика работает с мягкой пометкой в БД. Для нового продукта v3 срок 6–60 месяцев, персональная ставка от 20% с надбавками и скидками. Пять целей: закупка товаров/материалов, текущие расходы, сезонная закупка, оборудование и «Иное». Последняя не дает целевой скидки. Старые заявки v2 сохраняют 24% и прежний срок. Для авторизации нужна доступная PostgreSQL и учетные записи, созданные seed или CLI; работает путь от черновика до автоматического результата, а также дозапрос/новая отправка.

## Быстрый запуск backend

Нужны uv, Python 3.12 и существующая PostgreSQL 17.x. Из корня репозитория:

```powershell
uv sync --locked
if (!(Test-Path .env)) { Copy-Item .env.example .env }
uv run python -c "import secrets; print(secrets.token_urlsafe(48))"
```

В .env указать свою DATABASE_URL и вставить сгенерированный CSRF_SIGNING_KEY. Готовый .env не перезаписывать. Затем:

```powershell
uv run alembic upgrade head
uv run python -m credit_cabinet.seed --check-only
uv run python -m credit_cabinet.seed
uv run python -m credit_cabinet
```

При первом seed пароль НОВЫХ демо-аккаунтов запрашивается скрытым вводом; существующие пароли сохраняются. Клиенты: client@example.com (C01), client2@example.com (C02). Swagger: http://localhost:8000/docs; проверки: /health/live и /health/ready. Тесты: `uv run pytest -q`. Пошаговый cookie/CSRF-вход, банковский пользователь и параметры — [BACKEND.md](BACKEND.md).

## Условности ценообразования и развитие перед финалом

В демонстрационной версии рассматривается кредитование бизнеса без имущественного залога на срок 6–60 месяцев. Персональная ставка учитывает возраст бизнеса, кредитную историю, динамику операционных поступлений и срок. За длительность предусмотрена надбавка, отражающая принятую командой модель риска. База 20%, коэффициенты и скидки — демонстрационная политика команды, а не тарифы или методика конкретного банка.

Целевые скидки, льгота исправному действующему заёмщику нашего банка и скидка за партнёрскую покупку не снижают ставку ниже 20%. Внутренние отношения с банком заданы синтетикой; цель и партнёрская покупка заявляются клиентом без проверки договоров и целевого использования. Существующие долги учитываются в нагрузке. ИИ объясняет готовый расчет и не назначает ставку.

Из-за ограниченного времени отборочного этапа оценка залогового имущества и снижение ставки за обеспечение не реализованы. Перед финалом рассматриваем обеспеченное кредитование, проверку поставщиков по ИНН/внутреннему справочнику и документов, дополнительные цели с предложением категории LLM и явным подтверждением пользователя. Шесть исторических месяцев используются для демо без пятилетнего прогноза денежных потоков. Полные правила и источники ориентиров — [PRICING.md](PRICING.md).
